# 异地联机指南（浏览器 + frp）

## 先弄清一件事

`http://127.0.0.1:8765/` **只能在开主机的那台电脑上打开。**

- `127.0.0.1` =「这台电脑自己」
- 朋友用手机流量 / 别的宽带，访问你的 `127.0.0.1`，连的是**他自己的手机**，不是你的电脑

所以异地需要：**内网穿透（frp / OpenFrp）**，给房主电脑的 `8765` 端口一个公网地址。朋友浏览器打开的是：

```text
http://公网IP或域名:远程端口/
```

游戏逻辑仍在房主电脑；穿透只负责「把网页和 WebSocket 转进来」。

```text
朋友手机浏览器 ──HTTP/WS──► 公网入口(OpenFrp/frps)
                                │
                                │ 隧道
                                ▼
                       房主 PC: BoardGameHost (:8765)
                       （网页 + 权威对局）
```

---

## 异地测试流程（推荐：OpenFrp）

### 房主（电脑）

1. 双击运行 **`BoardGameHost.exe`**（或 `python -m boardgame_platform host --port 8765`）  
   - 本机可先打开 `http://127.0.0.1:8765/` 确认主页正常  
   - **黑窗口不要关**

2. 注册并登录 [OpenFrp](https://www.openfrp.net/)（或同类），下载官方客户端。

3. 创建一条 **TCP** 隧道：
   - 本地 IP：`127.0.0.1`
   - 本地端口：`8765`
   - 记下控制台给的 **公网节点地址** 和 **远程端口**（例如 `xxx.openfrp.com` 和 `12345`）

4. 启动 OpenFrp 客户端，确保这条隧道为「在线」。

5. 本机用浏览器再试一次公网地址（可选）：  
   `http://节点地址:远程端口/`  
   能打开主页就说明穿透成功。

6. 在网页里选「井字棋」→ **创建房间** → 复制 **房间号**，发给朋友。

### 朋友（其他网络 / 手机流量）

1. **不要**打开 `127.0.0.1`。  
2. 用系统浏览器打开房主发来的：  
   `http://节点地址:远程端口/`  
3. 选「井字棋」→ 填昵称 → 输入房间号 → **进入房间** → **准备**。  
4. 房主点 **开始游戏** → 双方用手机/鼠标点格子。

### 房主自己也可以

房主可以用 `127.0.0.1`，朋友必须用公网地址；也可以双方都用公网地址，更接近真实异地。

## 自建 frp（有云服务器时）

见仓库 `deploy/frpc.toml.example`：VPS 跑 `frps`，房主跑 `frpc`，把本地 `8765` 映射到 VPS 的某个端口。朋友打开：

```text
http://VPS公网IP:映射端口/
```

## 故障排查

| 现象 | 处理 |
|------|------|
| 朋友打不开页面 | 隧道是否在线；Host 是否在跑；地址/端口是否抄对；是否误用了 127.0.0.1 |
| 能打开页面但一直「未连接」 | 多半是 WS 被拦；确认用的是 `http://` 同一主机端口（页面会自动连 `ws://同一主机/ws`） |
| 进房失败 | 房间号是否一致；是否已开始；是否满员（井字棋 2 人） |
| 手机流量不行、WiFi 行 | 换 OpenFrp 节点；或检查运营商是否拦非常用端口 |
| 本机两个标签可以、异地不行 | 不是游戏逻辑问题，是穿透/公网地址问题 |

## 和「局域网」的区别

| 场景 | 地址 |
|------|------|
| 只在自己电脑两个浏览器标签试 | `http://127.0.0.1:8765/` |
| 同一 Wi‑Fi 另一台设备 | `http://房主局域网IP:8765/`（如 `http://192.168.1.8:8765/`） |
| 朋友用流量 / 外地宽带 | 必须 `http://穿透公网地址:端口/` |
